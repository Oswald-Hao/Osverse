# Tool icon sources and notices

Osverse renders tool icons locally and never loads a remote image at runtime.

The Anthropic, OpenCode, DeepSeek, Qwen, and GitHub Copilot vector paths are adapted from the corresponding Simple Icons glyphs under the Simple Icons CC0-1.0 license. Source: [simple-icons/simple-icons@c956d67](https://github.com/simple-icons/simple-icons/tree/c956d67dfa7c37ae65206fc0775b0c02d1e695c2). Retrieved 2026-08-17.

The ChatGPT tile uses the OpenAI knot shown for the official ChatGPT app in the [OpenAI Help Center](https://help.openai.com/en/articles/7905742-what-does-the-official-chatgpt-ios-app-icon-look-like). Its local 24×24 vector was adapted from the MIT-licensed OpenAI glyph in [farion1231/cc-switch v3.19.2](https://github.com/farion1231/cc-switch/blob/v3.19.2/src/icons/extracted/openai.svg).

The Codex tile uses the distinct terminal-in-knot Codex glyph from MIT-licensed [lobehub/lobe-icons@4aaf4ee](https://github.com/lobehub/lobe-icons/blob/4aaf4ee1fb2678a7f989ea570f0f6ce14a9abf75/packages/static-svg/icons/codex-color.svg). It is not substituted with the ChatGPT knot.

The Kimi Code tile adapts the 24×24 icon published by Moonshot AI in the MIT-licensed [Kimi Code repository at d1ca65e](https://github.com/MoonshotAI/kimi-code/blob/d1ca65e1de189617e9edbc54010e62d472a1de3d/apps/vscode/resources/kimi-icon.svg).

The CC Switch tile is the exact 128×128 application icon published in the MIT-licensed [CC Switch v3.19.2 source](https://github.com/farion1231/cc-switch/blob/v3.19.2/src-tauri/icons/128x128.png). Local SHA-256: `8e24e5968cac75da1698ae5c2cf2d5f542625bc9d2060b9a052f0348f9cf8795`.

The Cockpit Tools tile is the exact 128×128 application icon published in [Cockpit Tools v1.3.17 source](https://github.com/jlcodes99/cockpit-tools/blob/v1.3.17/src-tauri/icons/128x128.png). Local SHA-256: `adf31f26511a09fd60f76e099fd13e4761880138bb942153046c2ce261a9071c`.

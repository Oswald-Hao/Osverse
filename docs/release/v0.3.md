# Osverse 0.3 — Windows 首发 / Windows debut

Osverse 0.3 首次正式提供 Windows 10/11 x64 预发布版，同时继续提供 Ubuntu 20.04/22.04 x86_64 构建。

Osverse 0.3 is the first Windows 10/11 x64 prerelease and continues to ship native Ubuntu 20.04/22.04 x86_64 builds.

> `v0.3.0-beta.2` 修复了 Windows 桌面应用进入正常安装阶段时被错误显示为“安装服务返回了无效的任务状态”的问题。该错误来自前端状态校验，与代理速度无关。

## Windows 下载

- 推荐：`osverse-*-windows-amd64-setup.exe`，当前用户安装，不需要管理员权限。
- 免安装：`osverse-*-windows-amd64-portable.zip`。
- 单文件：`osverse-*-windows-amd64.exe`。

系统要求为 Windows 10/11 x64 与 Microsoft Edge WebView2 Runtime。安装包已嵌入 WebView2 bootstrapper。

## Windows 功能

- 从真实用户 PATH、固定应用目录、注册表与 Microsoft Store 包中发现已有 CLI 和桌面应用；已有工具不需要移动到 Osverse 目录。
- 检测、安装、更新和启动 Claude Code、Codex CLI、OpenCode CLI。
- 管理 Claude Desktop、OpenCode Desktop、CC Switch、Cockpit Tools，以及包含 Codex 的新版 ChatGPT Windows 应用。
- 使用固定下载 URL、精确长度和 SHA-256 校验安装源；Microsoft Store 安装使用固定 ID `9PLM9XGG6VKS`，不执行模糊搜索。
- API 档案仍以 AES-256-GCM 加密，主密钥再由当前 Windows 用户的 DPAPI 保护。
- 安全移除只接受后端固定身份；受管 CLI 移入 `%LOCALAPPDATA%\Osverse\recovery`，API 配置、凭据与登录会话默认保留。

## Windows downloads

- Recommended: `osverse-*-windows-amd64-setup.exe`, a per-user installer that needs no administrator access.
- Portable: `osverse-*-windows-amd64-portable.zip`.
- Standalone: `osverse-*-windows-amd64.exe`.

The Windows release discovers existing tools from the effective user environment, uses pinned and checksum-verified installers, protects profile keys with current-user DPAPI, and performs identity-checked launch and removal operations.

## Ubuntu

Ubuntu 用户应下载文件名中对应 `ubuntu20.04` 或 `ubuntu22.04` 的 `.deb`、AppImage 或便携 tar 包。Claude Desktop 仍只在 Ubuntu 22.04 及更高版本可安装；Linux 没有官方 ChatGPT Desktop，因此 Osverse 不提供非官方替代包。

## 验证下载

所有平台共用 `SHA256SUMS`，并提供 SPDX 2.3 SBOM、结构化更新清单和 GitHub OIDC 构建来源证明。

```bash
gh attestation verify <下载文件> --repo Oswald-Hao/Osverse
```

Windows PowerShell：

```powershell
(Get-FileHash .\osverse-*-windows-amd64-setup.exe -Algorithm SHA256).Hash
Get-Content .\SHA256SUMS
```

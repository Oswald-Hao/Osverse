# Osverse 0.9 — Kimi Code 跨平台接入

Osverse 0.9 将 Kimi Code 纳入统一的检测、校验安装、启动、移除和第三方 API 档案流程。已有外部 `kimi` 无需搬家；需要安装时，Osverse 使用 Moonshot AI 官方独立二进制，不依赖 Node/npm。

## 重点变化

- 检测用户真实命令路径中的 Kimi Code，并展示全部安装位置、解析目标和版本。
- 固定 Kimi Code `0.36.1` 六个平台制品的官方 URL、精确长度与 SHA-256；当前 Linux x64 和 Windows x64 应用启用事务式安装。
- ZIP 只允许一个固定普通可执行文件，提交前必须精确通过 `kimi --version`；版本目录不可变，命令入口与 PATH 原子切换并可回滚。
- 受管包装器关闭 Kimi 上游自动升级，防止后台下载绕过 Osverse 的统一验证。
- API 兼容矩阵支持 OpenAI Chat Completions、OpenAI Responses 与 Anthropic Messages，并使用 Kimi 原生 Provider 配置。
- 保留服务商提供的原始模型 ID；`osverse` 仅为本地 Provider/模型别名，不会出现在发往 API 的 `model` 字段中。
- 备份并原子更新 `~/.kimi-code/config.toml`，保留无关 TOML，拒绝覆盖没有 Osverse 所有权标记的同名配置。
- 总览、安装对话框、API 档案页、品牌图标、中英文 README、安全说明与使用指南同步更新。

## 验证

- 使用官方 Kimi Code `0.36.1` Linux x64 二进制完成真实流式端到端请求，验证 Bearer 凭据、规范化 Base URL 与精确模型 ID。
- 使用官方 Linux x64 与 Windows x64 Release 归档完成下载外的真实解压、版本和运行校验。
- 完整 Go、race、vet、前端测试、类型检查、生产构建、依赖审计以及 GitHub 原生 Windows/Ubuntu CI 作为发版门禁。

## English summary

Osverse 0.9 adds Kimi Code discovery, checksum-pinned standalone installation, launch, safe removal, and native third-party API profile support. It preserves existing external commands, installs without Node/npm, disables upstream self-update only for the managed runtime, and keeps the vendor's exact model ID on the wire.

The adapter backs up and atomically updates `~/.kimi-code/config.toml`, uses Kimi's native OpenAI Chat, OpenAI Responses, or Anthropic provider type, preserves unrelated TOML, and refuses unowned naming conflicts. Validation includes a real streaming request through the official Kimi Code `0.36.1` Linux binary plus official Linux and Windows archive verification.

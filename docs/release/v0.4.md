# Osverse 0.4 — 应用内更新与 Windows 发现修复

Osverse 0.4 加入跨平台应用内更新，并修复 Windows 上已有 Claude Code 与 OpenCode Desktop 被误判的问题。

## 重点变化

- 启动时静默检查 Osverse 官方 GitHub Release；发现新版本后展示版本号、更新说明和下载大小，由用户确认后再更新。
- Windows 下载并校验 NSIS 安装包，启动安装程序后安全退出旧版本。
- Linux 按当前安装方式更新：AppImage 和便携包校验后原子替换并重启，`.deb` 交给系统软件安装器确认。
- macOS 已接入同一套版本、清单、更新说明和 SHA-256 验证接口；macOS 安装包发布后会启用对应 DMG 流程。
- 更新地址、文件名、长度、摘要和安装命令全部由后端固定；界面只能提交一次性更新计划 ID。
- 已选择的本机 HTTP、HTTPS CONNECT 或 SOCKS5 代理也会用于检查和下载更新。

## Windows 检测修复

- Claude Code 可执行文件已经确认存在时，即使版本命令暂时失败，也会显示“已安装，版本暂时无法读取”，不会再误报安装异常。
- OpenCode Desktop 支持新版 `%LOCALAPPDATA%\Programs\@opencode-aidesktop` 和 `C:\Program Files\OpenCode` 目录。
- 同时读取卸载注册表中的 `InstallLocation` 与 `DisplayIcon`，能够识别自定义安装目录和多条历史安装记录。

## English summary

Osverse 0.4 adds confirmation-based, checksum-verified in-app updates across the supported Windows and Linux package formats, with the same update contract prepared for macOS. It also fixes Windows discovery for existing Claude Code installations whose version probe fails and for current or custom OpenCode Desktop install locations.

This is a prerelease. Report ordinary bugs through GitHub Issues. Use private vulnerability reporting for security problems, and never include a real API key or private endpoint in an issue.
